# Campus Smart Service Assistant (HarmonyOS)

A HarmonyOS campus assistant app built by a 3-person team. It won **Second Prize (National)** in the Application Development track of the 2024 Shanghai Jiao Tong University "Rongchang Cup" National Innovation Competition (2nd place in the track).

## Features

- Class schedule lookup
- Grade statistics
- Campus notice feed
- Multi-device handoff (distributed tasks continuing across devices)
